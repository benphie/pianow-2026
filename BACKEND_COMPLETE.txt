================================================================================
                          TROUBLESHOOTING
================================================================================

Problem: "Supabase is not configured!"
Solution:
  1. Check Settings → Integrations
  2. Confirm Supabase is connected (green status)
  3. Restart dev server
  4. Check browser console for errors

Problem: RLS Policy errors on query
Solution:
  1. Ensure user is authenticated
  2. Verify user has permission for the operation
  3. Check data belongs to current user
  4. For admin ops, verify user has 'admin' role

Problem: Profile not created after signup
Solution:
  1. Check email confirmation is complete
  2. Verify trigger exists: "on_auth_user_created"
  3. Check database logs for trigger errors
  4. Manually create profile if needed

Problem: Login fails with "Invalid email or password"
Solution:
  1. Verify email and password are correct
  2. Check user exists in auth.users table
  3. Confirm email is verified
  4. Check Supabase auth settings

See BACKEND_SETUP.md for more troubleshooting details.
