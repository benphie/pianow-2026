1. LOGGING A SIGNUP (in signup route)

   ----
   GET /api/analytics/signups?days=30&metric=byMethod

   {
     "byMethod": [
       { "signup_method": "email", "count": 150 },
       { "signup_method": "google", "count": 85 },
       { "signup_method": "kings_chat", "count": 23 }
     ]
   }

3. MARKETING CAMPAIGN URL
   ----
   https://pianow.app/signup?utm_source=facebook&utm_medium=paid&utm_campaign=summer_launch
   
   This will be automatically captured and stored in user_signups.

4. GET USER'S SIGNUP DATA
   ----
   import { getUserSignup } from '@/lib/db'
   
   const signup = await getUserSignup(userId)
   console.log(signup.device_type, signup.country, signup.utm_campaign)

5. ANALYZE GEOGRAPHIC TRENDS
   ----
   GET /api/analytics/signups?metric=byCountry&days=90

================================================================================
  📊 ANALYTICS API ENDPOINTS
================================================================================

GET /api/analytics/signups
  • Default: Returns all signups from last 30 days
  • Query: ?days=7 → Get last 7 days
  • Query: ?days=90 → Get last 90 days
  • Requires: Admin role

GET /api/analytics/signups?metric=byMethod
  • Returns signup breakdown by method
  • Example: { "email": 150, "google": 85, "kings_chat": 23 }

GET /api/analytics/signups?metric=byCountry
  • Returns signup breakdown by country
  • Sorted by count (most first)

GET /api/analytics/signups?metric=byReferralSource
  • Returns signup breakdown by traffic source
  • Includes referral_medium classification

GET /api/analytics/signups?metric=byDevice
  • Returns signup breakdown by device type
  • Shows desktop, mobile, tablet distribution
